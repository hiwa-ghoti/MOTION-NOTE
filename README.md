# MOTION NOTE — 動きの実験帳

HTML / CSS / JavaScriptのみで動く、23種類のアニメーション集です。

`index.html` をブラウザで開くと使えます。ローカルサーバーで確認する場合は、このフォルダで次を実行します。

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

http://127.0.0.1:4173 を開いてください。

- 一覧のカテゴリー切り替えと個別画面（URLのハッシュで遷移）
- 再生・一時停止、リセット、速度調整
- Web Audio APIによる効果音と演奏できる「Sound garden」
- 初期状態は閉じた「作り方とコード」、言語別タブとコピー
- キーボード操作、スマートフォン、動きを減らすOS設定に対応

音は各デモ内のボタンをタップしたときに、アニメーションと一緒に鳴ります。「タップ＆音」カテゴリーで探せます。波打つ文字列・縮小して戻る文字など6種類のテキストアニメーションもあります。各サンプルのコードは音の処理を含めてコピーできます。Google Fontsが取得できない場合もシステムフォントで動作します。

「Little wanderer」はassets/wandering-image.jpgをタップすると動き、もう一度タップすると停止します。公開時はassetsフォルダも一緒にプッシュしてください。画像の作り方・コードは個別画面から確認できます。

追加デモ：Color picnic（色の変化）、Jelly joy（ゼリー）、Tiny celebration（紙吹雪）、Catch me!（逃げる画像）、Hello, goodnight（昼夜切り替え）。すべてタップで音と動きが楽しめます。
